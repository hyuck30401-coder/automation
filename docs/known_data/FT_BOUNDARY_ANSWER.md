생성 `python tools/make_ft_boundary_data.py "Known Data"`

캘리브레이션 `python tools/calibrate_ft_boundary.py` (툴 실측으로 수렴, 결과는 `tools/known03_calib.json`)

## 무엇을 담았나

KNOWN01 이 "유형별로 맞게 분류되는가"를 본다면, 이 데이터셋은 **"경계에 있는 건이 실제 값으로
어느 정도인가"**를 본다. 각 선별 기준의 임계 × 0.90 / 0.96 / 0.99 / 1.01 / 1.04 / 1.10 지점에
유닛을 하나씩 심었다(게이트는 4단계). 한 그룹의 여러 단계는 **같은 항목 특성(mu·sigma·drift)과
같은 유닛 잡음**을 쓰므로, 단계 사이 차이는 오직 심은 유닛 하나뿐이고 물리량을 그대로 비교할 수 있다.

## 임계 바로 양옆(0.99 ↔ 1.01)의 실제 폭

| 기준 | 판정식 | 0.99 배 | 1.01 배 | 차이 |
|---|---|---|---|---|
| Excessive / Slight | `spec_margin_ratio = |값−한계|/|한계| ≥ 1%` | 0.990 | 1.010 | **0.020 %p** |
| Slight / Tail | `Mea_S·Diff_S 가 함께 Grubbs 임계 초과 → Slight` | 1.389 | 1.415 | **0.026 %p** |
| Abnormal Pass · Measured | `max|Mea_S| > Grubbs 임계` | 2.370 | 2.419 | **0.049 %p** |
| Abnormal Pass · Delta | `max|Diff_S| > Grubbs 임계` | 2.023 | 2.056 | **0.033 %p** |
| 스펙 대비 게이트 (Mea 축) | `|값−평균|/스펙폭 ≥ τ(5%) 면 유지` | 4.950 | 5.050 | **0.100 %p** |
| 스펙 대비 게이트 (Delta 축) | `|Post−Pre|/스펙폭 ≥ τ(5%) 면 유지` | 4.950 | 5.050 | **0.100 %p** |

전부 측정값의 **0.02 ~ 0.10 %p** 다. 그래프에서 두 유닛을 나란히 놓아도 구분되지 않는 폭이고,
보통 테스터 반복성과 같거나 그보다 작다. 반대로 **집단은 임계에서 한참 떨어져 있다** —
경계뷰의 각 그림에서 집단(파란 점)은 임계의 0 ~ 0.75 배 구간에 몰려 있다. 임계 자체는 집단과
확실히 구분되는 자리에 있고, 애매한 건 임계 바로 옆의 소수뿐이라는 뜻이다.

## 참고

- 판정은 **Room / 1000hrs** 에만 난다. 나머지 8개 조건은 fail 유닛 0.
  단 Mea 축 경계(M / P / MD)와 Slight 그룹은 **Pre 부터 집단에서 튀도록** 설계했으므로
  앞 회차에도 Abnormal Pass 로 잡히는 게 정답이다 (KNOWN01 과 같은 성질).
- `U_UNS_*` / `N_INT_*` 는 **같은 파일 안의 반복 행**(재시험, §3-4)으로 만든다.
  회차 파일이 아니라 행 반복이 재시험 단계다.
- `N_INT_IN` 은 회복값이 한계 바로 안쪽이라 Intermittent 인 동시에 Abnormal Pass(Measured)
  로도 잡힌다 — 기준상 맞는 동작이다.
- Grubbs 임계는 그 항목 pass 표본에 의존하고 심은 유닛 자신도 표본에 들어간다.
  그래서 knob 은 해석적으로 정해지지 않고 **툴 실측 → 할선법**으로 수렴시킨다(4~5 회 반복).
- Delta / TauDelta 단계는 **Pre 를 평균에 고정**한다. 안 그러면 이동량이 "그 유닛의 Pre 가
  어디였나"라는 난수에 지배당해 knob 을 움직여도 Diff_S 가 따라오지 않는다.
