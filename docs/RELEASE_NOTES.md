# 릴리즈 노트

리비전은 릴리즈 번호다. 태그는 리비전과 맞춘다 (`Rev.1.00` → `v1.0.0`).
태그는 **그 시점의 master 끝(HEAD)** 에 단다 — 중간 커밋에 달면 그 뒤 작업이 빠진다.

---

## Rev.1.00 (v1.0.0)

0.0.x 를 벗어난 첫 정식 버전. 담긴 범위는 **v0.0.29**(마지막으로 exe 가 올라간 릴리즈)
이후 전부 — **R-030 ~ R-099**.

### 판정 / 통계
- 분포 형상 기반 Tail 판정 (R-043), 실용적 유의성 게이트 (R-026 / R-029)
- Post Only 분석 (R-073) — Fail 판정은 불변, Abnormal Pass 는 변화량 축이 빠진다
- 재시험 이력 분리, 유닛 인구조사(`unit_counts`) 도입

### 화면
- 4분할 레이아웃과 조건 패널 접기, 신뢰성 항목 탭, Wafer Map
- 항목 / 샘플 두 기준 표, 유형 배지 필터 (R-064), 열 선택
- **R-091** — Fail 그래프에서 규격 이탈 점이 곡선과 CDF 1 위치에 두 번 찍히던 중복 제거
- **R-095** — 다른 항목에서 Fail 났지만 이 항목은 규격 안인 유닛을 회색 점으로 표시
  (CDF · Diff. CDF · Scattered Plot, 기본 켜기). **판정 통계에는 넣지 않는다**

### 데이터
- 폴더 규칙 기반 조건 선택, 4·5토막 병행 (R-079)
- 데이터 파일 저장 (R-080) — Pre / Post 를 한 번에 고르고 폴더 규칙대로 복사
- **R-092 / R-093** — 저장 창의 `Device` 를 `Product` 로, 입력칸 배치 정리

### 보고서
- Summary Table 을 템플릿 서식 그대로 채워 내보낸다 (R-083 / R-084)
- 시험 조건 입력 (R-087 / R-088) — 입력칸 사양을 템플릿 시트가 정한다
- 항목 체크와 `On-going` (R-089)
- Result 분모를 계획 수량(First ~ Last)으로 (R-090)
- **R-094** — 시험 조건 입력을 저장 창의 `Plan` 버튼으로 옮김

### 시험 등록 · Plan (R-096 ~ R-099)
- **R-096** — `Rel. Type` 을 고르면 그 Type 의 시험 항목이 미리 체크되고 조건도 채워진다.
  정본은 템플릿의 `Rel. Type 별 기본선택사항` 시트. `PCN Qual.` 이 Rel. Type 에 추가됐다.
  체크한 항목의 `Datasheet Spec.` 은 필수가 됐다.
- **R-097** — 왼쪽 패널의 `데이터 저장` 버튼이 **`시험 등록` / `데이터 저장` 둘로** 갈렸다.
  시험 등록은 데이터가 나오기 전에 조건 폴더와 `00_Pre`·`01_Post` 를 미리 만든다.
- **R-098** — `Qual.` 과 `PCN Qual.` 을 데이터 저장에서 쓸 수 없던 것을 고쳤다
  (폴더명 가운데 토막의 마침표 금지가 너무 넓었다).
- **R-099** — Plan 에 `S/S`(샘플 수량) 열이 생기고 `Last #` 는 `First # + S/S - 1` 로
  자동 계산된다(읽기 전용). 템플릿 `Condition 입력창` 의 조건 열이 한 칸 밀린 것도 맞췄다.

### 주의
- **`CACHE_SCHEMA` 33** — 기존 분석 캐시는 자동으로 무시되고 재분석된다. 첫 분석이 느리다.
- 판정 불변: 골든 회귀 게이트 legacy · shape 5건 PASS.
- 요구사항 99건 = 완료 78 / 검증대기 21.
- **exe 빌드는 아직 미해결이다.** v0.0.30 이후 `build-exe` 가 스모크 테스트에서 실패해
  Releases 에 exe 가 붙지 않는다 (소스로 실행하는 데는 문제 없다).
